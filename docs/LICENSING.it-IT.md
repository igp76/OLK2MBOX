## Binari dell’applicazione e sorgente

Ogni release dell’applicazione identifica il proprio codice sorgente corrispondente tramite un tag firmato. Per l’app 2.0.0 utilizzare [`app-v2.0.0`](https://github.com/igp76/OLK2MBOX/tree/app-v2.0.0). GitHub fornisce gli archivi sorgente `.zip` e `.tar.gz` nella stessa pagina della release che contiene DMG e ZIP dell’applicazione.

Il bundle dell’applicazione contiene:

- `Contents/Resources/Licenses/GPL-3.0.txt`;
